# コントローラー（CC）とセットアップファイル

## 1. どの音色でも効くコントローラー

次の CC は、プリセットの設定に関係なく、**すべての音色・すべてのパート（MIDI チャンネル）**で効きます。フィルターが「off」のサンプル音色（SonicCell・GM など）でも同じです。割り当て（MIDI Learn）は要りません。

| CC | 名前 | 効き方 |
|---|---|---|
| 1 | モジュレーション | ビブラート（5.5 Hz、最大 ±0.5 半音）。プリセットがモジュレーションマトリクスでホイールを使っているときは、そちらの設定が優先され、ビブラートは付きません |
| 5 | ポルタメントタイム | 0 = プリセットのまま。1〜127 で約 5 ms〜2 秒のポルタメントになります（ポリでも、前の音から滑ります）。Mono / Legato のプリセットでは、そのグライド時間を置き換えます |
| 11 | エクスプレッション | パートの音量（2 乗カーブ、127 = そのまま）。プリセットがモジュレーションでエクスプレッションを使っているときは、そちらが優先されます |
| 71 | レゾナンス | 64 = プリセットのまま。上げると強く、下げると弱くなります |
| 74 | ブライトネス（カットオフ） | 64 = プリセットのまま。上下に最大 ±4.5 オクターブ。フィルターのない音色では、64 未満にすると 12 dB のローパスがかかって暗くなります（64 以上は元の音のまま） |
| 91 | リバーブ | センド A（リバーブ）に足されます（127 で +0.6） |
| 94 | ディレイ | センド B（ディレイ）に足されます（127 で +0.6） |

ほかに CC7（ボリューム）・CC10（パン）はマルチモードで、CC64（ダンパー、ハーフペダル対応）・CC121（リセット）・RPN 0（ベンド幅）はいつでも効きます。

- CC71・74・91・94・5 は、CC121（リセット・オール・コントローラー）では戻りません（GM2 の決まりどおり）。曲の再生開始と停止のときは戻ります。
- MIDI Learn で上の CC をパートのパラメーターに割り当てると、**そのパートでは割り当てが標準の効き方に置き換わります**（例: エレピのパートだけ CC1 をトレモロの深さにすると、そのパートではビブラートが付かなくなります。ほかのパートは標準のまま）。割り当てを消すと、次にその CC が来たときに標準に戻ります。

### 自作キーボードの割り当て

| マルチプレクサ | 名前 | CC | HSynth での効き方 |
|---|---|---|---|
| 0 | Wheel | 1 | ビブラート |
| 2 | Volume2 | 5 | ポルタメントタイム |
| 3 | Volume1 | 11 | エクスプレッション（音量） |
| 4 | Volume3 | 71 | レゾナンス |
| 5 | Volume4 | 74 | カットオフ（明るさ） |
| 6 | Volume5 | 91 | リバーブ |
| 7 | Volume6 | 94 | ディレイ |

つまみの中央（64）が「プリセットのまま」になるのは CC71 と CC74 だけです。CC5・91・94 は 0 が「足さない」、CC11 は 127 が「そのまま」です。

## 2. セットアップファイル（設定の書き出し・読み込み）

パートごとの MIDI チャンネル・プリセット・ミックス（音量・パン・鍵域）、エフェクト、MIDI Learn の割り当て、同時発音数・品質を 1 つのファイル（`hsynth-setup` 形式の JSON）にまとめて書き出し・読み込みします。PC 版・Android 版・iPhone 版で同じファイルが使えます。

| アプリ | 場所 |
|---|---|
| PC（Windows / macOS） | Monitor 画面 →「Setup (export / import)」→「Export setup...」/「Import setup...」。`desktop/data/setups/` に置いたファイルは「Load 名前」ボタンで 1 回で読み込めます |
| Android | Multi 画面 →「セットアップを書き出す…」/「セットアップを読み込む…」 |
| iPhone / iPad | System 画面 →「Setup」パネル →「Export…」/「Import…」/「Save to setups」、`setups` フォルダーのファイルは「Load 名前」 |
| PC から SysEx で | `hsynth_remote.py setup-save band.json` / `setup-load band.json`（[SYSEX.md](SYSEX.md)） |

- サンプルの場所は、ライブラリのフォルダーからの相対パスで入っています。読み込む側にも同じライブラリ（例: `library/user/soniccell/...`）が必要です。
- 書き出したときにシングルモードならシングルの音色として、マルチモードなら 16 パートとして読み込まれます。
- オーディオ機器名やバッファーなど、その機械に固有の設定は入りません。
- どのアプリで書き出したファイルも、どのアプリでも読み込めます。設定（`host`）は、各アプリが自分の持っている項目を書き、読むときは自分に関係する項目だけを使います（ほかは無視）。

| `host` の項目 | 意味 | Windows | Mac | iPhone | Android |
|---|---|---|---|---|---|
| `voices` | 同時発音数 | ○ | ○ | ○（上限 128） | ○ |
| `quality` | 品質 0 Low / 1 Normal / 2 High | ○ | ○ | ○ | ○ |
| `mpe` | MPE で受ける | ○ | ○ | － | ○ |
| `umpInput` | MIDI 2.0（UMP）で受ける | － | ○ | ○ | － |
| `screenOn` | 開いている間は画面を消さない | － | － | ○ | 常にオン |
| `background` | バックグラウンド・画面オフでも演奏できる | － | － | ○ | － |

- 置き場所: Windows / Mac は `desktop/data/setups/`、iPhone は「ファイル」アプリの HSynth > `setups`（System 画面の「Load …」ボタン、「Save to setups」で保存）。

## 3. おすすめセットアップ「SonicCell Keyboard」

SonicCell のサンプル音色を、MIDI チャンネルごとに 1 つずつ割り当てたセットアップです。キーボードの送信チャンネルを切り替えると音色が変わります。**1〜10ch に必須の音色**、11〜16ch にあると便利な音色を入れています。

表に書いていない CC は、すべてのチャンネルで 1 章の標準の効き方です。「割り当て」の欄にある CC だけ、そのチャンネルでは別の役目にしています（パートのエフェクトを動かします）。

| ch | 音色 | 用途 | 割り当て（そのチャンネルだけ） |
|---|---|---|---|
| 1 | A 001 Rich Grand | グランドピアノ | CC1 = コーラス（広がり） |
| 2 | A 044 Tine EP | エレピ | CC1 = ステレオトレモロ（オートパン）の深さ |
| 3 | B 003 FullDraw Org | オルガン | CC1 = コーラスの速さ（ロータリー風 slow → fast）、CC71 = オーバードライブ |
| 4 | C 047 String Ens | ストリングス | —（CC11 でクレッシェンド、CC1 でビブラート） |
| 5 | D 004 Stereo Brass | ブラス | —（CC74 で明るさ） |
| 6 | G 005 Silk Pad | パッド | CC1 = ゆっくりしたフェイザー |
| 7 | D 077 Classic Lead | シンセリード | —（CC1 ビブラート、CC5 ポルタメント、CC74 / 71 フィルター） |
| 8 | B 075 FingerMaster | フィンガーベース | CC1 = ドライブ（歪み） |
| 9 | D 018 Super Saw | スーパーソウ / ポリシンセ | —（CC74 でスイープ） |
| 10 | Rhythm 005 StandardKit1 | ドラム（GM と同じ 10ch） | CC1 = DJ フィルター（上げるとこもる）、CC5 = フィルターのレゾナンス（ドラムの音程が滑らないように） |
| 11 | B 049 Clean Gtr | クリーンギター | CC1 = オートワウ |
| 12 | G 059 Choir Aahs 1 | クワイア | — |
| 13 | A 113 SC Vibe | ビブラフォン | CC1 = モーター（トレモロ） |
| 14 | D 036 Tenor Sax | テナーサックス | —（CC11 で抑揚） |
| 15 | B 101 SH-101 Bs 1 | シンセベース | —（CC74 / 71 フィルター） |
| 16 | A 073 Cell Clav | クラビネット | CC1 = オートワウ |

- 割り当てはセットアップの MIDI Learn に入っています。読み込むと、今の MIDI Learn の割り当てはこのセットアップのものに置き換わります。
- CC1 の割り当てがあるチャンネルは、ホイールを 0 にするとエフェクトがかからない（元の音）状態です。

ファイルは `desktop/tools/make_soniccell_setup.py` で作ります（エンジンが実際に書き出すので、アプリの書き出しと同じ形式になります）。

```bash
python desktop/tools/make_soniccell_setup.py --copy C:/HSynth-iPhone/setups
```

できたファイルは `desktop/data/setups/SonicCell Keyboard.json`（PC 版の「Load SonicCell Keyboard」）と、`--copy` で指定したフォルダーです。iPhone では `HSynth-iPhone/setups` を「ファイル」アプリで HSynth のフォルダーに入れてから「Import…」で選びます。SonicCell の音を使うので、テスト用です（配布しないでください）。
